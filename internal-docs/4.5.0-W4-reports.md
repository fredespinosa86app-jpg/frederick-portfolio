# 4.5.0 W4 - history and reports (internal)

This repository is public. Nothing secret belongs in this file.

## What it is
A read-only page module (`scripts/owner-wtreport.js`) over a pure module (`scripts/core-wtreport.js`). No new collection, no rules change, no writes of any kind.

## Reads (Spark: 50,000 a day)
1. `workSessions` where `date >= from` and `date < to + 1 day` (single-field range on the stored local date string; no composite index).
2. For each session: `workEvents`, `workCorrections`, `workAssign`, each filtered by `sid ==` (equality only; no index). Six sessions at a time.
3. `clientRegistry` once when the page opens (for the Client ID list).
Estimate = sessions x 13 typical, sessions x (1 + 12 events + 10 clients + 20 corrections) at most. Above 60 sessions the owner confirms; above 150 it refuses. Range at most 92 days.

## Row model (`buildRow`)
original = `derive(events)`; effective = `effective(events, corrections)` when valid and closed, else the original (`fellBack`, warning). Status: complete / incomplete (closed with CLOSE_INCOMPLETE) / open / invalid (bad order, or no punches). Only complete sessions are in totals.

## Grouping
Day = `workSessions.date` (the local day at clock-in in the session's own zone). Week = the current `workSettings.weekStart`. Month = first 7 characters of the day. Client rows count each session once per client and are never summed.

## CSV
23 columns (see `COLUMNS`). `cell()` quotes per RFC 4180 and prefixes `'` to anything starting (after optional spaces) with `=`, `+`, `-`, `@`, or starting with tab or CR. BOM + CRLF.
