# 4.5.0 B2 - invoices (internal)

Public repository: nothing secret here.

Collections (owner only, create-only except invoices, no deletes): invoices (ID CLIENTID__YYYYMMDD__YYYYMMDD[__NN]), invoiceAudit, payments, paymentReversals (ID = payment ID), invoiceAdjustments, invoiceDueDates.
Invoice step: `lastKind` (create, ready, send, cancel, payment, credit, reversal, adjustment, due) + `lastRef` = the brand-new paired record, same batch, rev+1.
Entries: link (APPROVED, no invoice, DRAFT invoice in same batch) / unlink (invoice cancelled).
Logic: `scripts/core-invoice.js` (plans), `scripts/owner-invoices.js` (page). Decisions: `4.5.0-B2-decisions.md`.
Tests: core-invoice.test.mjs, attack 8j-8l, mutations_b2.py + b2_equiv.py, qa_b2, emulator invoices-b2.test.mjs (demo-invoices2).
