    I use Amazon Seller Central to verify product availability and eligibility within the client's seller account. My primary uses include:

          This site is run by Frederick Espinosa (Philippines). It follows the Data Privacy Act of 2012 (Republic Act 10173). To ask about your data, send a discovery call request through the form on this page and say it is a privacy request.

          What is collected

          Visits. The site counts visits without cookies and without your name, email, IP address or exact location. Each record has a random anonymous ID kept in your browser, the sections viewed (saved together as one short list when you leave), the website you came from (host name only), device type, browser name and the time. You can switch this off below, and the site respects Do Not Track and Global Privacy Control.

          Discovery call requests. If you send one, the name, email, company, preferred date and time, time zone, platform, message and any answers you give are stored so the owner can reply to you.

          Outside booking calendar. If the owner uses a third-party booking calendar on the Discovery Call page, the details you enter there are collected by that provider under its own privacy policy, not stored on this site.

          Chatbot. Questions the chatbot cannot answer are saved with a random chat ID (no name or email) so answers can be improved. If an AI service is connected, your message is sent to it through a private relay to produce a reply.

          Why and how long

          Only to run the site, answer you and improve it; nothing is sold or used for advertising. Visit records are kept up to 90 days, chatbot questions up to 180 days, finished discovery call requests up to 2 years (confirmed meetings count as finished 30 days after their date), and requests that were never answered up to 1 year. Details of people who become clients are kept for as long as the working relationship and legal record keeping need.

          Who can see it

          Only the owner, in a private database (Google Firebase) that visitors cannot read. The website is hosted on GitHub Pages. No data is shared with advertisers.

          You may ask to see, correct, export or delete your data, object to its use, or withdraw consent, and you may complain to the National Privacy Commission (privacy.gov.ph). Requests are answered personally.

                /* Google Sheets receiver for the portfolio owner panel (Enhancement E4).
   SETUP (about 5 minutes, free, your own Google account):
   1. Create a new Google Sheet. Open Extensions > Apps Script and paste this whole file (replace the sample code).
   2. Click the gear icon (Project Settings) > Script properties > Add script property:  name TOKEN,  value a long random
      text (at least 16 characters, for example 4 random words and 6 digits). Keep a copy: the owner panel needs the same text.
   3. Click Deploy > New deployment > type "Web app". Execute as: Me.  Who has access: Anyone.  Deploy and authorise.
   4. Copy the Web app URL (ends with /exec). In the owner panel open Integrations > Google Sheets, paste the URL and the TOKEN, press Save, then Test.
   Only requests that carry your TOKEN are accepted. The sheet tabs are created for you. Re-sending the same rows updates them (no duplicates).
   To stop: in the owner panel press Disconnect, and in Apps Script choose Deploy > Manage deployments > Archive. */
var TABS = {
  Meetings: ['id', 'created', 'status', 'name', 'email', 'company', 'service', 'date', 'time', 'timezone', 'platform', 'message'],
  Clients: ['id', 'name', 'email', 'phone', 'company', 'rate', 'arrangement', 'invoice due', 'status', 'notes'],
  Visitors: ['id', 'date', 'visits', 'unique visitors', 'page views', 'sections viewed']
};
function out_(o) { return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }
function clean_(v) {
  v = String(v == null ? '' : v).replace(/[\u0000-\u0008\u000B\u000C\u000E-\u001F]/g, '').slice(0, 1000);
  return /^[=+\-@\t\r]/.test(v) ? "'" + v : v;   // a cell can never start a formula
}
function doPost(e) {
  try {
    var b = JSON.parse(e.postData.contents);
    var t = PropertiesService.getScriptProperties().getProperty('TOKEN');
    if (!t || t.length < 16 || !b.token || b.token !== t) return out_({ ok: false, error: 'denied' });
    if (b.action === 'ping') return out_({ ok: true, pong: true });
    var cols = TABS[b.tab];
    if (!cols || !Array.isArray(b.rows) || b.rows.length > 200) return out_({ ok: false, error: 'bad request' });
    var lock = LockService.getScriptLock(); lock.waitLock(20000);
    var added = 0, updated = 0;
    try {
      var ss = SpreadsheetApp.getActiveSpreadsheet(), sh = ss.getSheetByName(b.tab) || ss.insertSheet(b.tab);
      if (sh.getLastRow() === 0) { sh.getRange(1, 1, 1, cols.length).setValues([cols]).setFontWeight('bold'); sh.setFrozenRows(1); }
      sh.getRange(1, 1, Math.max(sh.getMaxRows(), 2), cols.length).setNumberFormat('@');   // plain text: never a formula
      var last = sh.getLastRow(), ids = {};
      if (last > 1) sh.getRange(2, 1, last - 1, 1).getValues().forEach(function (r, i) { ids[String(r[0])] = i + 2; });
      var fresh = [];
      b.rows.forEach(function (r) {
        if (!Array.isArray(r) || !r.length) return;
        var row = []; for (var i = 0; i < cols.length; i++) row.push(clean_(r[i]));
        if (!row[0]) return;
        if (ids[row[0]]) { sh.getRange(ids[row[0]], 1, 1, cols.length).setValues([row]); updated++; } else { fresh.push(row); }
      });
      if (fresh.length) { sh.getRange(sh.getLastRow() + 1, 1, fresh.length, cols.length).setValues(fresh); added = fresh.length; }
    } finally { lock.releaseLock(); }
    return out_({ ok: true, added: added, updated: updated });
  } catch (err) { return out_({ ok: false, error: 'failed' }); }
}

                  Then
                  1. In GitHub: repository Settings > Pages > Custom domain, enter the domain and Save (or commit a file named CNAME containing it).

A safety copy of the current data is downloaded before the restore starts.
                  


                  

                  

                  

                  

                  How long personal data is kept
                  

                  Discovery call requests: finished ones (completed or cancelled) are deleted after the first period. Unanswered ones (new or pending) are flagged after the second and deleted after the third. A confirmed meeting is never touched while it is ahead; 30 days after its date it counts as finished. There is no background job on the free plan, so cleanup runs when you press the button below, and a reminder appears on your dashboard once a week when something is due. The periods you choose are shown to visitors in the privacy notice. Clients are never deleted automatically.
